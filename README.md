# ネットルーティン

毎日決まった順番で見て回るWebサイトを、カテゴリ順に1つずつ巡回するための自分専用ツールです。

- **PC版**: Windows の Chrome 拡張機能。開いたページの下部にナビバーが出ます
- **iPhone版**: ホーム画面に追加して使うWebアプリ（PWA）。アプリ画面がナビの役目をします
- 2つは同期しません。一覧は JSON の書き出し・読み込みで移します

## 使い方（共通）

| 操作 | 動き |
| --- | --- |
| 次へ ▶ | 今日まだチェックしていない、次のサイトを開く |
| 次カテゴリ ⏭ | 今のカテゴリの残りを飛ばして、次のカテゴリの最初の未訪問サイトを開く |
| ◀ 前へ | 一覧の順で1つ前のサイトを開く |
| ☰ 一覧 | 全サイトとチェック状態を表示する。サイト名を押すとそのサイトへ移動する（PC版は移動後も一覧が開いたまま。各カテゴリ縦4行で折り返し、はみ出したら横スクロール／ホイールでも横に動く） |
| ✓ | チェックを手動で付け外しする |
| ✎ 編集（PC版のみ） | 「編集画面」（全画面のタブ）か「サイドパネル」（ページの横）を選んで開く |

- アプリから開いたサイトには、自動でチェックが付きます。飛ばしたサイトは未チェックのまま残ります
- 全部チェックし終わった後も、「次へ」は一覧の順で1つ次へ、「次カテゴリ」は次のカテゴリの先頭へ進めます
- 最後のサイト（最後のカテゴリ）で「次へ」（「次カテゴリ」）を押すと最初に戻ります。未巡回が残っていれば未巡回の最初のサイトへ、全部巡回済みなら最初のサイト（カテゴリ）へ移動し、ナビの直上にその旨をトーストで数秒表示します
- チェックは **毎日 午前5時** にリセットされます。履歴は残りません

## PC版（Chrome 拡張機能）の導入

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダの `extension` を選ぶ
4. 編集画面が開くので、サイトを登録する（`samples/sample-routine.json` を読み込めば、すぐに試せます）
5. ツールバーのアイコン（パズルのマークからピン留めすると便利）→「巡回を開始」

### YouTube チャンネルの新着チェック（PC版。iPhone版は下の「iPhone版で YouTube の新着チェックを使う」を参照）

`youtube.com/@名前`・`youtube.com/channel/...` などのチャンネルページを登録すると、自動で新着チェックの対象になります。

- このアプリから最後に開いた日時と、チャンネルの最新動画の公開日時を比べます
- **前回開いた後に新しい動画がないチャンネルは、「次へ」「次カテゴリ」で自動的に飛ばします**（チェックは付きませんが、巡回完了の判定では済み扱い）
- **新着動画があるチャンネルは、チャンネルページの代わりに新着動画を直接開きます**。1本ならその動画、複数なら古い順に並べた一時プレイリストで続けて再生します（フィードで分かる最新15本まで）
- **ショート動画は数えません**（再生もしません）。ショートしか新しいものがなければ「新着なし」です
- 「新着」は前回アプリから開いた後に公開された動画という意味で、YouTube 上で実際に見たかどうかではありません
- 一覧には「新着なし」と表示されます。一覧から選べば（チャンネルページが）開けます
- 確認するのは、巡回を開始したときと30分ごとです
- 一度もアプリから開いていないチャンネルや、確認に失敗したチャンネルは飛ばしません
- アプリを通さずに YouTube で見た分は数えません
- チャンネルごとに、編集画面の「新着チェック」で対象から外せます。同じ行に、最新動画・前回開いた日時・判定が表示されます

### 自動巡回（PC版のみ）

カテゴリごとに、一定の秒数で次のサイトへ自動で進めます。

1. 編集画面で、カテゴリの「**自動巡回**」にチェックを入れ、「**表示秒数**」（1〜99秒の半角数字）を入れる。秒数はチェックを入れたときだけ入力できます（最初は10秒）
2. ナビバーの「◀ 前へ」の左にある「**自動巡回ON**」にチェックを入れる

- 自動巡回のカテゴリのサイトを表示すると、「あと○秒」と数え、0秒になったら「次へ」と同じ動きで次のサイトへ進みます
- 自動巡回でないカテゴリに入ると止まります。「自動巡回ON」を外しても止まります
- 巡回タブが見えていない間（別のタブやウィンドウを見ているとき）と、「✎ 編集」のメニューを開いている間は、数えるのを止めます
- iPhone版は、サイトを別のブラウザで開く仕組みのため自動では進められず、この機能はありません（設定は JSON の書き出し・読み込みでそのまま保たれます）

### ブラウジングしながら登録する（サイドパネル）

ツールバーのアイコン →「サイドパネルで編集」で、編集画面がブラウザの横に開きます。
いつものタブで Google などからページを開き、サイドパネルのボタンを押すと登録できます。

- **登録**（各行）: 表示中のページの URL を、その行に入れる（サイト名はそのまま）
- **今のページを追加**（各カテゴリの下）: 表示中のページを、ページ名ごとそのカテゴリに追加する
- パネルの上部に、今どのページが対象になっているかが表示されます
- サイドパネルを左側に出したいときは、Chrome の 設定 → デザイン →「サイドパネルの位置」で変更できます

- 巡回用のタブは1つだけで、使い回されます。巡回タブの中でリンクをたどっても、ナビバーは表示されたままです
- ナビバーは ▼ で折りたためます
- `chrome://` で始まるページや Chrome ウェブストアなど、一部のページにはナビバーを表示できません

## iPhone版の公開と導入

### 1. GitHub Pages に公開する（最初の1回）

1. GitHub で新しいリポジトリを作る（GitHub Pages を無料で使うには **Public** にする）
2. このフォルダをそのリポジトリに push する
3. リポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」にする
4. **Actions** タブで「Deploy iPhone app to Pages」が成功すると、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

公開されるのは `iphone/` フォルダのプログラムだけです。登録したサイトの一覧は、各端末の中にだけ保存されます。

### 2. iPhone のホーム画面に追加する

1. iPhone の Chrome（または Safari）で上の URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「巡回」アイコンから起動する

**注意**: ホーム画面から起動したアプリの保存領域は、ブラウザで開いたときの保存領域とは別です。サイトの登録や JSON の読み込みは、必ず **ホーム画面のアイコンから起動した状態で** 行ってください。

### iPhone版での巡回のしかた

1. 「次へ」などを押すとサイトがブラウザで開き、チェックが付く
2. 見終わったらアプリに戻る（画面左上の戻るリンクや、アプリの切り替えで戻る）
3. 「次へ」で次のサイトへ進む

「↗ 開く」で、今のサイトをもう一度開けます。

### iPhone版で、ブラウザで見ているページを登録する（コピー経由）

1. 登録したいページで 共有ボタン →「コピー」（URL がコピーされる）
2. 「巡回」アプリの「編集」を開く
3. カテゴリの下の **「コピーしたURLを追加」** を押す（既存の行の URL を差し替えるときは、その行の **「貼り付け」**）
4. 「ペースト」の確認が出たら押す

サイト名はドメイン名（例: news.yahoo.co.jp）で登録されるので、必要なら直してください。
コピーした文字が「タイトル（改行）URL」の形なら、タイトルがサイト名になります。

### iPhone版で YouTube の新着チェックを使う（中継サーバーの準備）

iPhone のWebアプリは YouTube のデータを直接読めないため、無料の Cloudflare Workers に小さな中継サーバー（`cloudflare/worker.js`）を置きます。最初の1回だけ必要です。

1. https://dash.cloudflare.com/sign-up でアカウントを作る（無料プラン）
2. 左メニュー「Workers & Pages」→「作成（Create）」→「Hello World から開始」→ 名前を `net-routine-yt` にして「デプロイ」
3. 「コードを編集（Edit code）」を押し、中身を全部消して `cloudflare/worker.js` の内容を貼り付け →「デプロイ（Deploy）」
4. 表示される URL（`https://net-routine-yt.○○.workers.dev`）をコピー
5. iPhone の「巡回」アプリ →「編集」→ 一番下の「YouTube の新着チェック」に URL を貼り付けて「保存して確認」

- 中継サーバーが応答するのは、公開中のアプリ（`https://knkuaj-gc-8011.github.io`）からの問い合わせと、YouTube のチャンネルの問い合わせだけです
- 新着の確認は、アプリを開いたとき・サイトから戻ってきたとき（同じチャンネルは5分以内に再確認しない）・開いている間は30分ごと
- 前回閲覧日時は iPhone 版で開いた日時です（PC版とは別々に記録します）
- 新着動画の直接再生・ショートの除外も PC版と同じです。「↗ 開く」は、直前に開いたもの（新着動画の再生リストなど）を開き直します
- `cloudflare/worker.js` を更新したときは、Cloudflare の「コードを編集」で中身を貼り直して「デプロイ」してください（GitHub に送っただけでは中継サーバーは変わりません）

## PC版の一覧を iPhone に移す

1. PC版の編集画面 →「コピー」（または「ファイルに書き出す」）
2. iPhone へ送る（自分宛てのメモやメッセージに貼る、iCloud Drive にファイルを置く、など）
3. iPhone版の「編集」→ JSON を貼り付けて「貼り付けた JSON を読み込む」（またはファイルから読み込む）

## 開発者向け

```
shared/      共通ロジック core.js と編集画面 editor.js / editor.css の正本
extension/   Chrome 拡張（Manifest V3）
iphone/      GitHub Pages で公開する PWA
tests/       node:test によるテスト
scripts/     sync-core.ps1（正本をコピー）、make-icons.js（アイコン生成）
samples/     サンプルの一覧 JSON
```

- `shared/` を変更したら、`scripts/sync-core.ps1` で `extension/` と `iphone/` にコピーする
  ```
  powershell -ExecutionPolicy Bypass -File scripts\sync-core.ps1
  ```
- テスト: `node --test tests/core.test.js`（コピー漏れも検出します）
- iPhone版の手元での確認: `npx serve iphone` を実行し、PC のブラウザの開発者ツールでスマホ表示にする
- iPhone版を更新したのに古い表示のままなら、`iphone/sw.js` の `CACHE` の番号を上げる
